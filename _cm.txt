fix: insights "7 Hari Terakhir" showed month-to-date, not 7 days

Real defect found by auditing the insights page, not from the PRD list.

The section is labelled "7 Hari Terakhir" but rendered dash.monthlyExpense —
month-to-date. Any spending earlier in the month inflated the figure, so the
page overstated how fast money was leaving.

Proven with a fixture that separates the two windows:
  - expense on day 1 of this month  = 700000  (in month, outside 7 days)
  - expenses within last 7 days     = 300000
  - page showed 1000000, should show 300000

Fixed by summing getSpendingFlow(), which is already filtered to the last 7
days and to expenses only — no new query needed. The now-unused getDashboard()
call was removed rather than left as a wasted round-trip.

The test guards its own fixture: if run in the first week of the month the two
windows overlap, so it reports SKIPPED instead of passing vacuously.
