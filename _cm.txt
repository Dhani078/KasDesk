feat: verify auth end-to-end over HTTP; fix pb-safe, zoom, branding

Adds a repeatable HTTP test suite (npm run test:auth) that drives the real
Auth.js credentials flow with curl: CSRF issuance, login, session
resolution, protected-route access, and rejection of a wrong password.
12/12 pass against the production server. The earlier "failures" were bugs
in a Node fetch-based harness that did not forward the CSRF cookie, not
defects in the auth code.

fix: pb-safe was a dead class - Tailwind v4 needs @utility to register a
custom utility, so the bottom nav had no safe-area padding on notched
devices. Now compiled into the built CSS (verified: 1 occurrence, was 0).

fix: removed maximumScale/userScalable from the viewport. Disabling
pinch-zoom fails WCAG 2.2 SC 1.4.4 (Resize Text).

chore: rename package vaultify -> kasdesk, app title Vaultify -> KASDESK,
and add the accent/danger/surface/border tokens the auth screens use.
